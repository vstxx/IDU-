# IDU+

Fresh MV3 visual-layer extension for the real IDU DOM.

## What is included

- `manifest.json` loads the extension on `https://*.idu.edu.pl/*`.
- `src/idu-plus.css` applies the glassy productivity-dashboard redesign.
- `src/idu-plus.js` adds the scoped `html.idu-plus` class and cleans the legacy subject list into modern rows while preserving the original links.
- `fonts/` bundles the local Inter font files from the audit.

## Local install

Open Chrome or Edge extension settings, enable developer mode, choose "Load unpacked", and select this `IDU+` folder.
