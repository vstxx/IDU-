Privacy Policy for IDU+

Last updated: June 25, 2026

IDU+ is a browser extension that customizes and modernizes the visual interface of the IDU school portal. This privacy policy explains what the extension does, what information it stores, and what information it does not collect.

Summary

IDU+ works locally for appearance settings and sends a small diagnostics event after a logged-in user is detected. Diagnostics are used only to understand active usage and debug browser compatibility.

How IDU+ Works

IDU+ runs on IDU portal pages and applies a local visual layer to the existing portal. It may read the structure and visible content of the currently opened IDU page only so it can apply interface improvements, layout changes, and appearance settings.

IDU+ does not replace the official IDU portal, does not create a separate account system, and does not change school records or portal data.

Information Stored Locally

IDU+ stores appearance preferences and a locally generated diagnostics install ID using browser extension storage. Appearance preferences may include:

  • selected theme, such as light or dark mode
  • accent color
  • topbar color
  • title font choice
  • layout mode, such as portal or sidebar layout

These settings are used only to remember the user's customization choices and apply them consistently when the IDU portal is opened again.

Basic Diagnostics Sent

When IDU+ detects a logged-in IDU page, it may send the displayed full name and basic technical diagnostics to a Cloudflare Worker, which forwards the event to a private Discord channel controlled by the developer. The event includes only:

  • displayed full name
  • extension version
  • browser name if available
  • IDU host or domain
  • timestamp
  • locally generated install ID

IDU+ reports a displayed name only once per installation. After a successful first report, the same person is not reported again from that installation.

Information IDU+ Does Not Collect

IDU+ does not collect passwords, cookies, grades, messages, page contents, or screenshots. It also does not collect or transmit:

  • usernames, passwords, authentication tokens, cookies, or login credentials
  • messages, grades, attendance records, documents, profile information, or other school data
  • full page HTML, screenshots, or copied page contents
  • browsing history
  • financial information
  • health information
  • location data

No Analytics, Advertising, or Tracking

IDU+ does not use external analytics providers, advertising systems, tracking scripts, or remote code. All JavaScript, CSS, fonts, images, and other extension assets are packaged with the extension.

Data Sharing

IDU+ does not sell or rent user data. The only external diagnostics path is the limited event described above, sent through Cloudflare Worker to a private Discord webhook.

Permissions

IDU+ requests only the permissions needed to customize and modernize the IDU portal interface. Storage is used to save appearance settings. Access to IDU portal pages is used to apply the extension's visual improvements on the portal. The extension does not request access to all websites.

Contact

If you have questions about this privacy policy, contact the developer through the IDU+ GitHub repository.
