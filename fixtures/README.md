# Fixtures

Put anonymized IDU HTML snapshots here only if needed for local debugging.

Do not commit or share:

- passwords,
- cookies,
- session tokens,
- HAR files,
- private messages,
- real addresses / phone numbers / PESEL.

Recommended files, if you create them locally:

```txt
fixtures/dashboard.html
fixtures/profile.html
fixtures/login.html
fixtures/grades.html
fixtures/mobile-dashboard.html
```

The extension itself does not require these fixtures to run in Chrome. They are only for Codex/source review.
